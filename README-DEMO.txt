RAYYSTR WEBSITE - VERSI DEMO

CARA MENJALANKAN:
1. Ekstrak ZIP ini.
2. Buka folder RAYYSTR-WEBSITE.
3. Klik dua kali index.html untuk melihat website di browser.
   Jika browser membatasi fitur, jalankan server lokal: buka CMD di folder ini lalu ketik: python -m http.server 8000
   Buka http://localhost:8000

HALAMAN/FITUR:
- Beranda premium dark gaming
- Marketplace akun Free Fire, Mobile Legends, PUBG Mobile
- Hubungi seller melalui WhatsApp
- Form jual akun (listing menunggu moderasi)
- Pengajuan promosi WhatsApp
- Paket VIP dan nomor transaksi demo
- Form laporan penipu dan daftar laporan terverifikasi
- Dashboard admin demo untuk moderasi listing/promosi/laporan/pesanan
- Responsive untuk HP dan desktop

PENTING:
Ini adalah prototipe front-end. Data disimpan di localStorage browser masing-masing, belum tersinkron online. Login, verifikasi admin, upload bukti, QRIS, dan transaksi nyata belum aman/terhubung backend. Untuk online publik, hubungkan database/auth (misalnya Supabase) dan deploy ke Vercel/hosting. Jangan masukkan data pembayaran nyata ke versi demo.
